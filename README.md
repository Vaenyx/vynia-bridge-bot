# Vynia Discord Bot

Vynia Discord Bot is a lightweight Discord Bot built to be easily extensible and run commands of all kinds using both internal and external services.


## Features

- Discord bot functionality
- Docker deployment
- Environment-based configuration
- Minimal and easy to extend
